# 퀘스트콜 앱

퀘스트콜 웹앱과 안드로이드 앱 배포용 저장소입니다.

- 웹앱: https://inquamlife-ops.github.io/questcall-app/
- 안드로이드 앱(APK): [최신 버전 받기](https://github.com/inquamlife-ops/questcall-app/releases/latest/download/questcall.apk)

## 안드로이드 설치
1. 위 링크로 `questcall.apk`를 받습니다.
2. 열면 "출처를 알 수 없는 앱" 경고가 나옵니다. 설정에서 이 출처(크롬 등) 설치를 허용합니다.
3. 설치 후 앱의 캐릭터 탭 → "안드로이드 모닝콜"에서 권한 세 가지를 켭니다.
